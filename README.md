# NUTHH Downloader Bot

Telegram bot for downloading YouTube and TikTok videos/audio with a license key system.

## Features

- 🎬 YouTube Video Download
- 🎵 YouTube/TikTok MP3 Download
- 🔑 License Key System
- ⏳ 1 Day / 7 Days / 30 Days / 90 Days / 1 Year / Lifetime
- 👑 Owner Panel
- 👥 User Management
- 📢 Multiple Telegram Channel Posting
- 🗑 License Revoke/Delete
- 👤 Owner/User Role Management
- 🆔 User ID
- 💾 SQLite Database
- 🚀 Railway Deployment
- ☁️ GitHub Deployment
